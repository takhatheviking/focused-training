# Google Таблица с участниками и заказами

Бот ведёт одну Google Таблицу и обновляет её сам:

- **лист на каждый ивент** — участники: код билета, имя, телефон, Telegram, тип билета, статус («Прошёл» подсвечен зелёным), время входа;
- **«Все заказы»** — заказы по всем ивентам: статус с цветом, покупатель, сумма, карта, модератор, время создания и оплаты.

Листы обновляются раз в 2 минуты, если данные изменились. Сразу — по кнопке «⚙️ Админка → 📗 Google Таблица → 🔄 Синхронизировать сейчас». В таблицу попадают опубликованные и отменённые ивенты, а также прошедшие за последние 30 дней. Черновики не попадают.

Бот пишет в таблицу через сервисный аккаунт Google — отдельную учётную запись для программ. Она видит только те таблицы, которые вы ей откроете.

## 1. Сервисный аккаунт и ключ (один раз, ~5 минут)

1. Откройте [console.cloud.google.com](https://console.cloud.google.com) и создайте проект, например `focused-bot`. Подойдёт и существующий.
2. **APIs & Services → Library** → найдите **Google Sheets API** → **Enable**.
3. **IAM & Admin → Service Accounts → Create service account**. Имя любое, например `focused-sheets`. Роли не нужны, нажмите **Done**.
4. Откройте созданный аккаунт → вкладка **Keys → Add key → Create new key → JSON**. Скачается файл с ключом.
5. Переименуйте файл в `google-service-account.json` и положите в папку `secrets` проекта: `D:\Work\Labs\Focused_bot\secrets\google-service-account.json`. На сервере — в `secrets/` рядом с `docker-compose.yml`.
6. Перезапустите бота:

   ```bash
   docker compose up -d bot
   ```

> Если Google пишет, что создание ключей запрещено политикой организации (`iam.disableServiceAccountKeyCreation`), то это ограничение рабочего Google Workspace. Создайте проект в личном Google-аккаунте или попросите администратора Workspace разрешить ключ для этого проекта.

## 2. Таблица

1. В боте откройте **⚙️ Админка → 📗 Google Таблица**. Там показан адрес сервисного аккаунта, вида `focused-sheets@…iam.gserviceaccount.com`.
2. Создайте пустую Google Таблицу. Нажмите **Настройки доступа**, добавьте этот адрес с правами **Редактор**. Уведомление можно не отправлять.
3. В боте нажмите **🔗 Указать таблицу** и пришлите ссылку на таблицу. Бот проверит доступ и сразу заполнит листы.

Указать или сменить таблицу могут только владельцы из `ADMIN_IDS`, остальные админы получат об этом уведомление. Синхронизировать вручную может любой админ.

## Важно

- **Ключ — это пароль.** Не пересылайте его в чатах и не кладите в git: папка `secrets/` уже исключена из git и из Docker-образа и подключается в контейнер только для чтения. Если ключ утёк, удалите его в **Keys** и создайте новый.
- **Правки в таблице руками затираются** при следующей синхронизации: бот считает базу источником правды. Пометки и формулы делайте на отдельном листе, ссылаясь на листы бота.
- **Переименовывать и двигать листы можно**: бот находит их по внутреннему id. Удалённый лист бот создаст заново.
- **Если синхронизация перестала работать** (закрыли доступ, удалили таблицу, отключили API), админы получат одно сообщение с причиной, а текст ошибки появится на экране «📗 Google Таблица».
