# Focused · Moliyaviy Savodxonlik — лендинг с формой заявки

Одностраничный лендинг для 4-часового тренинга по финансовой грамотности (11 октября 2026, ISFT). Собирает лиды в Google Sheets через Apps Script.

## Что внутри

```
focused-training/
├── index.html              ← лендинг (Hero → проблемы → результаты → программа → FAQ → форма)
├── config.js               ← URL Apps Script (вписать после деплоя)
├── app.js                  ← i18n UZ/RU, валидация, отправка, sticky CTA
├── google-apps-script.gs   ← приёмник заявок в Google Sheets
└── README.md
```

## Структура лендинга

1. **Hero** — дата, время, место, суббед, чипы преимуществ, CTA
2. **Проблемы** (5 карточек из ТЗ) + bridge-текст
3. **Результаты** (5 deliverables из ТЗ) + note про образовательный формат
4. **Программа дня** — таймлайн 14:30–19:00, подсвечены рабочие сессии
5. **FAQ** — 6 частых вопросов из ТЗ
6. **Форма заявки** — имя, телефон, канал (TG/звонок), source, боль, consent
7. **Sticky CTA** на мобильных

## Отличия от полного ТЗ (осознанно упростили)

Это **lead-capture MVP**, не платёжный лендинг. Что вынесено за скобки:
- Онлайн-checkout и платёжный webhook — платит человек уже через менеджера
- VSL с UTM-роутингом (Jamshid/Dildora) — можно добавить позже
- CRM-интеграция — работаем через Google Sheets
- Тикеты, Meta Conversions API, полная аналитика — не нужны на этом этапе
- Блоки Focused-кредита, спикеров с фото, материалы-preview — по мере готовности контента

**Что осталось из ТЗ** (важное):
- Тон: сдержанный, без обещаний «финансовой свободы»
- Только подтверждённые факты (дата, время, место, цена)
- Дисклеймер про образовательный формат в футере
- Оба языка (UZ по умолчанию, RU переключается)

## Деплой — 3 этапа

### Этап 1. Google Sheets + Apps Script

1. Создай таблицу на <https://sheets.google.com> (название: `Focused — Zayavkalar`).
2. Extensions → Apps Script.
3. Удали стартовый код, вставь `google-apps-script.gs` целиком. Сохрани.
4. В выпадашке функций сверху выбери **`setupSheet`** → **Run**. Разреши доступ.
5. (Опционально) Запусти `testSubmission` — появится тестовая строка. Удали её потом.
6. **Deploy → New deployment**:
   - Type: **Web app**
   - Description: `Focused Apply v1`
   - Execute as: **Me**
   - Who has access: **Anyone**
   - Deploy → копируй **Web app URL**.

### Этап 2. Подключить фронт

Открой `config.js`, замени `PASTE_YOUR_GOOGLE_APPS_SCRIPT_URL_HERE` на URL из шага 6. Сохрани.

### Этап 3. Залить на GitHub Pages

1. Создай публичный репо на GitHub → загрузи все 5 файлов через **Add file → Upload files**.
2. Settings → Pages → Source: `main` / `(root)` → Save.
3. Через минуту откроется на `https://твой-username.github.io/имя-репо/`.

## Тон и границы (важно для менеджеров)

Из ТЗ (стр. 6, 8, 33):
- **Не** обещать «доход вырастет», «долги за день исчезнут», «100% результат»
- **Не** называть спикеров экспертами / миллионерами без подтверждения
- **Не** говорить про lunch/coffee break — их нет
- Цена = 50 000 сум, входит воркбук и шаблоны
- Курс Focused (700 000) — **опциональное** предложение в конце тренинга, не обязательно
